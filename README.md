Artin AI 🤖

Artin AI is a personal project that I’m actively working on. It is an AI-powered Telegram bot built with Python, with several useful features added over time.

Features

- 💬 AI-powered conversations
- 🧠 Long-term memory
- 🌐 Web search
- 🗄️ SQLite database
- 🔧 Modular project structure
- 🔌 API integration
- 🤖 AI-powered responses using Grok

Tech Stack

- 🐍 Python
- 📱 python-telegram-bot
- 🧠 Grok API
- 🗄️ SQLite
- 🔧 Git & GitHub

About the Project

I started Artin AI as a personal project to learn more about Python, Artificial Intelligence, APIs, and software development by building something practical.

The project has gradually grown from a simple Telegram bot into a more complete AI assistant with features such as long-term memory, web search, database integration, and AI-powered conversations.

I’m continuing to improve the project, experiment with new ideas, and add new features over time.

Getting Started

1. Clone the repository

git clone git@github.com:USERNAME/Artin-AI.git
cd Artin-AI

2. Install dependencies

pip install -r requirements.txt

3. Configure the bot

Create a "config.py" file based on "config.example.py" and add your own API keys and Telegram bot token.

4. Run the bot

python bot.py
